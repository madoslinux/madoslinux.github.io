madOS: Local AI Orchestration Under Your Full Control

Linux distribution for running, auditing, and managing open models without leaving your machine.

Download madOS Audit Code

Why madOS is Different

We understand the skepticism around "AI" in the Linux community. madOS is built on transparency, sovereignty, and user control—not extraction.

🏠

Everything Runs Locally

All tools execute on localhost. No external connections required. Your data never leaves your hardware unless you explicitly configure otherwise.

📜

Open Licenses Only

We ship only models with libre licenses: MIT, Apache 2.0, or DFSG-compatible. Full list available at /docs/models.

🚫

No Hidden Agendas

No telemetry, no closed APIs, no data harvesting. What you see is what you get—verified by public source code.

Built for Developers & Privacy-Conscious Users

madOS treats AI as a tool, not a replacement. You decide when, how, and which models to use.

🛠️

Ollama Integration

Pre-configured Ollama setup for seamless local model management and inference.

🐍

Python-Based Tooling

All orchestration scripts written in Python—readable, modifiable, and auditable.

🔐

OpenCode Framework

Transparent AI assistance framework with full visibility into prompts and outputs.

📦

Model Sandboxing

Models run in isolated environments when possible, limiting system access.

📋

Dependency Transparency

Complete package list with hashes. No obfuscated dependencies.

✅

Verified Updates

All updates signed with GPG. Audit changes before applying.

Security & Privacy by Design

Every architectural decision prioritizes your sovereignty and safety.

🔒

Offline-First Execution

The distribution works completely without internet. Any network functionality requires explicit manual activation by the user.

👁️

No Hidden Telemetry

No background processes sending data anywhere. All logs are local and under your control.

🧪

Model Isolation

Models execute in sandboxed environments where feasible, restricting their system access.

📊

Transparent Dependencies

Full package list with cryptographic hashes available. Nothing hidden.

🔑

GPG-Signed Images

All ISO images include SHA256 checksums and GPG signatures for verification.

🔍

Auditable Codebase

Part of the code was AI-assisted, but every line was reviewed, audited, and signed by humans. Public repository for inspection.
